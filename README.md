# Elevate Labs Task 4 - Logistic Regression

## Task 4: Classification with Logistic Regression

This project implements a binary classification model using Logistic Regression.

### Dataset
Breast Cancer Wisconsin Dataset.

### Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

### Work Done
- Loaded and cleaned the dataset
- Split the data into training and testing sets
- Standardized the features
- Trained a Logistic Regression model
- Evaluated the model using:
  - Confusion Matrix
  - Precision
  - Recall
  - ROC-AUC
- Performed threshold tuning
- Visualized the Sigmoid function

### Objective
To build and evaluate a binary classification model using Logistic Regression.
